# DayFlow — Productivity OS

A full-stack SaaS productivity app built from scratch.

🔗 **Live site:** https://morningtodo.netlify.app

## Features
- 🔐 User authentication (Supabase Auth)
- ☁️ Cloud database with per-user data isolation (Supabase)
- 📅 Daily task scheduling with time blocks
- 🔥 Habit tracker with streak chains
- 📊 Weekly analytics and deep performance review
- 🍅 Pomodoro focus timer
- 🏆 XP, badges, and gamification
- 🤖 AI Coach section
- 📱 Fully responsive — mobile, tablet, desktop

## Tech Stack
- Frontend: HTML, CSS, Vanilla JavaScript
- Backend: Supabase (PostgreSQL + Auth)
- Deployment: Netlify
- Design: Bricolage Grotesque + Inter fonts, dark/light theme

## Architecture
- Row Level Security ensures each user only sees their own data
- Real-time sync indicator shows cloud save status
- localStorage fallback for theme preferences
